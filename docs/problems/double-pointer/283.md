# 283. 移动零
[283. 移动零](https://leetcode.cn/problems/move-zeroes/)

**谁告诉你要移动0的？**

和[27](27.md)没有本质区别，就是把27的查找数字改成0,然后加一步,把后面全改成0.

## 完整代码
```cpp
class Solution {
  public:
	void moveZeroes(vector<int> &nums)
	{
		int slow = 0, fast, n = nums.size();
		for (fast = 0; fast < n; fast++) {
			if (nums[fast] != 0) {
				nums[slow] = nums[fast];
				slow++;
			}
		}
		while (slow < n) {
			nums[slow] = 0;
			slow++;
		}
	}
};
```
